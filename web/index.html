📖 Albumatic Help & Mount Catalog

1. How Template Notation Works

A template like ABBA-hh-BBB defines rows separated by dashes (-). Each letter defines a stamp mount size:

  • Uppercase letters (A–Z): Portrait or square stamp mounts (e.g. A = 20×24 mm / 0.79×0.94 in, B = 20×26 mm, X = 35×35 mm).
  • Lowercase letters (a–v): Landscape stamp mounts (e.g. a = 24×21 mm / 0.94×0.83 in, h = 36×25 mm).

2. Defining Custom Sizes (e.g., X, Overrides & Arbitrary Dimensions)

Standard X is 35×35 mm (Hawid square). You can override X or assign custom dimensions to any character code (e.g. X, Z2, 1):

  • In the Web Designer: Expand "Custom Mount Sizes" inside the Stamp Rows & Mounts card, enter the code (e.g. X) and dimensions (e.g. 45 × 30 mm), then click + Set Size.
  • In Stateless URLs / Query: Append ?size_X=45,30 or ?s_X=45,30 (width, height in current unit).
  • In Batch Notation: Add | s:X=45,30 to the page record (e.g. 1881 | 1 | Custom Issue | XXX | s:X=45,30 | t:1_1=Blue).
  • In REST JSON API: Include "custom_sizes": {"X": [45.0, 30.0]} in the PageConfig payload.

4. Full International Unicode Support

Titles, inner texts, and labels support the complete UTF-8 Unicode character set:

  • European accents & diacritics: cliché, brût, penniä, Frimärke, Åbo, Görlitz
  • Cyrillic & Slavic: Россия, Москва, СССР, 1 коп.
  • Greek: Ελλάς, Ερμής, λεπτά
  • Devanagari / Asian scripts: नेपाल, 日本
  • Symbols & Fractions: ½A, ¼d, №, ★, €, £, ¥
